# بوت وموقع إدارة سيرفر الكومنتي

المشروع كامل (البوت + الموقع) بمجلد واحد مسطح بدون أي مجلدات فرعية، ويشتغلون **بنفس العملية** (process) عن طريق `index.js` — يعني تنشره كـ **خدمة واحدة بس على Railway**.

---

## الخطوة 1: إنشاء تطبيق ديسكورد

1. روح [Discord Developer Portal](https://discord.com/developers/applications)
2. اضغط **New Application** واعطيه اسم
3. تبويب **Bot**:
   - **Reset Token** وخذ التوكن (`DISCORD_TOKEN`) — احفظه، ما يظهر مرة ثانية
   - فعّل **MESSAGE CONTENT INTENT** و **SERVER MEMBERS INTENT**
4. تبويب **OAuth2 > General**:
   - انسخ **Client ID** (`CLIENT_ID`)
   - انسخ **Client Secret** (`CLIENT_SECRET`)
   - بقسم **Redirects** ضيف: `https://رابط-موقعك/auth/discord/callback` (نعدله بعد النشر)

## الخطوة 2: دعوة البوت لسيرفرك

من **OAuth2 > URL Generator**: اختر Scopes: `bot` و `applications.commands`، والصلاحيات: Manage Roles, Manage Messages, Kick Members, Ban Members, Moderate Members, Move Members, Mute Members, Manage Channels, Manage Guild, Manage Guild Expressions, Send Messages, Read Message History, Add Reactions, Embed Links. افتح الرابط وادعِ البوت.

## الخطوة 3: إنشاء قاعدة بيانات MongoDB (مجانية)

1. روح [MongoDB Atlas](https://www.mongodb.com/cloud/atlas/register) وسوي حساب مجاني
2. أنشئ Cluster مجاني (Free Tier — M0)
3. من **Database Access**: أنشئ يوزر وباسورد لقاعدة البيانات (احفظهم)
4. من **Network Access**: اضغط **Add IP Address** واختر **Allow Access from Anywhere** (0.0.0.0/0) — عشان Railway يقدر يوصلها
5. من **Connect > Drivers** انسخ رابط الاتصال، شكله:
   ```
   mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/discord_bot?retryWrites=true&w=majority
   ```
   بدّل `username` و`password` باللي سويتهم فوق — هذا هو `MONGODB_URI`

## الخطوة 4: رفع المشروع على GitHub

سوي Repository جديد وارفعله كل ملفات المشروع (كلها بمجلد واحد).

## الخطوة 5: النشر على Railway (خدمة واحدة)

1. روح [Railway](https://railway.app) وسجل دخول بحساب GitHub
2. **New Project > Deploy from GitHub repo** واختر الريبو
3. **Settings > Networking** → **Generate Domain** — يعطيك رابط الموقع
4. رجع لـ Discord Developer Portal وحدّث رابط الـ Redirect بالضبط: `https://رابطك/auth/discord/callback`
5. من تبويب **Variables** ضيف كل هذي (كلها بنفس الخدمة، ما فيه تقسيم):
   - `DISCORD_TOKEN`
   - `CLIENT_ID`
   - `CLIENT_SECRET`
   - `CALLBACK_URL` → رابط موقعك + `/auth/discord/callback`
   - `MONGODB_URI` → رابط الاتصال من MongoDB Atlas (الخطوة 3)
   - `SESSION_SECRET` → نص عشوائي طويل ([randomkeygen.com](https://randomkeygen.com))
6. Deploy — البوت والموقع يشتغلون مع بعض بنفس اللحظة، والفهارس تنشأ تلقائي أول مرة

## الخطوة 6: التجربة

افتح رابط الموقع، سجل دخول بديسكورد، اختر السيرفر وعدل الإعدادات. جرب بديسكورد: `مساعدة` (دليل كل الأوامر)، `/اقتراح` `/استطلاع` `/المتصدرين`، `بروفايل`، وأوامر الإدارة زي `دي @فلان`.

## الخطوة 7 (اختياري): تفعيل نظام الموسيقى

نظام الموسيقى يحتاج **خدمة منفصلة** تشتغل بجنب خدمة البوت (سيرفر Lavalink) — الأغاني ما تتشغل من داخل كود البوت نفسه.

1. بنفس مشروع Railway اضغط **+ New > Empty Service**
2. سمّها أي اسم (مثلاً `lavalink`)
3. من **Settings > Source**، اربطها بنفس الريبو، وحدد **Root Directory** = `/lavalink`
4. من **Variables** بهذي الخدمة (مو خدمة البوت) ضيف:
   - `LAVALINK_PASSWORD` → كلمة سر تختارها (لازم تكون **نفسها بالضبط** بخدمة البوت كمان)
   - `SPOTIFY_CLIENT_ID` و`SPOTIFY_CLIENT_SECRET` (اختياري، لدعم روابط سبوتيفاي — من [developer.spotify.com](https://developer.spotify.com))
   - `DEEZER_MASTER_KEY` (اختياري، لدعم دييزر)
5. Deploy، وبعدها من **Settings > Networking** فعّل **Private Networking** أو **Generate Domain** (حسب احتياجك) — خذ الدومين/العنوان الداخلي
6. ارجع لخدمة **البوت** وضيف بـ Variables:
   - `LAVALINK_HOST` → دومين خدمة لافا لينك اللي طلع لك
   - `LAVALINK_PORT` → `2333` (افتراضي)
   - `LAVALINK_PASSWORD` → **نفس القيمة بالضبط** اللي حطيتها بخطوة 4
   - `LAVALINK_SECURE` → `true` لو الدومين HTTPS، أو `false` لو شبكة داخلية

## الخطوة 8 (اختياري): تفعيل نظام السينما

بس ضيف `TMDB_API_KEY` لمتغيرات خدمة البوت — مجاني وفوري من [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api).

## أمر المساعدة

اكتب `مساعدة` بأي وقت لعرض دليل كامل لكل الأوامر مبوب حسب النوع، أو `مساعدة اسم-القسم` (مثال: `مساعدة الأعضاء`) لعرض قسم معين بالتفصيل. متاح للكل، وكل عضو يقدر يستخدم بس الأوامر اللي عنده صلاحيتها فعليًا.

## صفحات لوحة التحكم

الموقع صار فيه 3 صفحات لكل سيرفر، متنقل بينهم من شريط علوي:
- **⚙️ الإعدادات** — نفسها القديمة (ترحيب، رتب، فلترة، مستويات...)
- **📊 الإحصائيات** — عدد الأعضاء، المتصلين، إجمالي الرسائل، أعلى مستوى، الإنذارات، الاقتراحات، وقائمة المتصدرين
- **⚠️ الإنذارات** — عرض كل عضو عنده إنذارات مع إمكانية حذف إنذار وحد أو الكل مباشرة من الموقع بدون داخل ديسكورد

## أوامر السلاش

| الأمر | الوظيفة |
|---|---|
| `/اقتراح` | تقديم اقتراح مع تصويت وخط تقدم |
| `/استطلاع` | إنشاء استطلاع رأي بخيارات متعددة |
| `/المتصدرين` | أفضل 10 أعضاء بالمستوى |

> **ملاحظة:** أمر البروفايل صار أمر نصي عادي زي باقي أوامر الإدارة — اكتب `بروفايل` (أو `بروفايل @عضو` لعرض بروفايل غيرك) بدون سلاش.

## أوامر الإدارة (بدون سلاش — تكتب مباشرة بالرسالة)

كل أمر محمي بصلاحية ديسكورد **حقيقية ودقيقة** — العضو يحتاج بالضبط نفس الصلاحية اللي ديسكورد نفسه يستخدمها لهذا الإجراء (مو صلاحية عامة أوسع من اللازم). يعني لو أعطيت عضو صلاحية "Ban Members" بس، يقدر يستخدم أوامر الحظر بس، ولو أعطيته "Timeout Members" يقدر يستخدم الكتم بس، وهكذا — نفس منطق ديسكورد الأصلي بالضبط. الأدمن (Administrator) يقدر يستخدم كل الأوامر تلقائيًا بغض النظر عن التفاصيل.

| الصلاحية بديسكورد | الأوامر المرتبطة فيها |
|---|---|
| Kick Members | `دي` (طرد) |
| Ban Members | `اعدام` `اعفاء` `سجن` `محي` |
| Timeout Members (Moderate Members) | `لتمضرط` `مضرط` `تحذير` `تحذيرات` `شيل` `شيل_الكل` `سجل_عضو` |
| Manage Nicknames | `دلع` |
| Manage Messages | `مسح` `مسح_عضو` `مسح_يحتوي` `مسح_بوتات` `تثبيت` `الغاء_تثبيت` `اعلان` |
| Manage Channels | `قفل` `فتح` `قفل_الكل` `فتح_الكل` `انشاء_قناة` `حذف_قناة` `تسمية_قناة` `تصنيف` `بطء` `بطء_الغاء` `نقل_قناة` `قفل_الروم_الصوتي` |
| Manage Roles | `اعطاء_رتبه` `سحب_رتبه` `انشاء_رتبه` `حذف_رتبه` `اعطاء_رتبه_للكل` |
| Move Members | `سحب_صوت` `نقل_صوت` |
| Mute Members | `كتم_صوت` `فك_كتم_صوت` |
| Manage Guild Expressions | `اضافة_ايموجي` `حذف_ايموجي` `قائمة_الايموجي` |
| Manage Guild | `الدعوات` `حذف_دعوة` `تغيير_اسم_السيرفر` `تغيير_شعار_السيرفر` `دخول` `خروج` |
| Administrator فقط (إجراء شامل ما يطابقه صلاحية وحدة) | `نسخة_احتياطية` `استعادة` |

**الأعضاء:** `طير @عضو [سبب]` • `اعدام @عضو [سبب]` • `اعفاء [آيدي]` • `سجن @عضو 10د [سبب]` • `محي @عضو [سبب]` • `كتم @عضو 10د [سبب]` • `مضرط @عضو` • `نك @عضو [اسم]`

**التحذيرات:** `تحذير @عضو [سبب]` • `تحذيرات @عضو` • `شيل @عضو [رقم]` • `شيل_الكل @عضو`

**الرسائل:** `مسح [عدد]` • `مسح_عضو @عضو [عدد]` • `مسح_يحتوي [كلمة]` • `مسح_بوتات` • رد على رسالة واكتب `تثبيت` أو `الغاء_تثبيت`

**القنوات:** `قفل` • `فتح` • `قفل_الكل` • `فتح_الكل` • `انشاء_قناة [اسم]` • `حذف_قناة` • `تسمية_قناة [اسم]` • `تصنيف [اسم]` • `بطء [ثواني]` • `بطء_الغاء` • `نقل_قناة [التصنيف]`

**الرتب:** `اعطاء_رتبه @عضو [رتبة]` • `سحب_رتبه @عضو [رتبة]` • `انشاء_رتبه [#لون] [اسم]` • `حذف_رتبه [اسم]` • `اعطاء_رتبه_للكل [رتبة]`

**الصوتيات:** `سحب_صوت @عضو` • `نقل_صوت @عضو [روم]` • `كتم_صوت @عضو` • `فك_كتم_صوت @عضو` • `قفل_الروم_الصوتي [اسم]`

**السيرفر:** `اعلان [نص]` • `الدعوات` • `حذف_دعوة [كود]` • `تغيير_اسم_السيرفر [اسم]` • `تغيير_شعار_السيرفر` (أرفق صورة)

**الايموجي:** `اضافة_ايموجي [رابط] [اسم]` • `حذف_ايموجي [اسم]` • `قائمة_الايموجي`

**السينما:** `فيلم [اسم]` • `مسلسل [اسم]` • `نشاهد_سوا [اسم]` • `ليلة_سينما`

**الموسيقى:** `تشغيل [اسم/رابط]` • `ايقاف_مؤقت` `استمرار` • `تخطي` `رجوع` • `صوت [0-150]` • `تقديم` `ترجيع` • `الطابور` • `خلط` • `تكرار` • `ازالة [رقم]` • `فلتر [باص/نايت_كور/فيبورويف/دوران/رعشة/كاريوكي]` • `جودة` • `وقف` • `الأغنية_الحالية`

**أخرى:** `سجل_عضو @عضو` • `تعديل_بيانات @عضو` • `نسخة_احتياطية` • `استعادة [آيدي]` (يطلب تأكيد)

⚠️ رتبة البوت لازم تكون **أعلى** من رتبة أي عضو تطبق عليه أمر (كيك/حظر/كتم/رتب)، وإلا ما راح ينفذ.

## ملاحظات مهمة

- **البوت والموقع يشتغلون بنفس العملية (process)** — لو صار خطأ يوقف العملية كاملة، راح يوقف الاثنين مع بعض (هذا الفرق الأساسي عن نشرهم كخدمتين منفصلتين)
- **خدمة واحدة بس على Railway** — أرخص وأبسط بالإدارة، بس معناها أي إعادة نشر (Deploy) تعيد تشغيل البوت والموقع مع بعض
- الجداول تنشأ تلقائي أول مرة يشتغل فيها المشروع، ما تحتاج تسويها يدوي
- كل الأسرار (Variables) بمكان واحد بس بالخدمة — ما فيه تقسيم بين بوت وموقع بعد الآن
